# Webflow build kit

Generated by `python3 webflow_export.py` from the production build. Everything here fits Webflow's 50,000-character code limits.

| File | Goes where in Webflow |
|---|---|
| `site-head.html` | Site settings → Custom code → Head (theme + gear-shift script, fonts, CSS part 1) |
| `css-part-2.html` | Embed inside the site-wide header component (CSS part 2) |
| `site-footer.html` | Site settings → Custom code → Footer (site script) |
| `header.html`, `footer.html` | Site-wide header and footer components |
| `site-chrome.html` | Embed in the footer component: rev line, shift band, gear HUD, booking pop-up |
| `pages/…` | The `<main>` of each page, English and `es/` |
| `page-meta.json` | Title, description, `data-gear`, language and JSON-LD per page |
| `cms/categories.csv`, `cms/posts.csv` | Blog CMS import (10 categories, 41 posts) |
| `../docs/redirects.csv` | Site settings → Publishing → 301 redirects |

`{{ASSET_BASE}}` in the CSS is replaced with the Webflow asset URL once the images are uploaded.
Bookings, Elfsight and Boast are already in the page files with the live site's own IDs.
